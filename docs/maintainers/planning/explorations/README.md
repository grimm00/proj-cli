## 🎯 Overview

This directory contains active explorations, proof of concepts, and abstract ideas being explored before research and decision phases.

**Purpose:**
- Organize thoughts before committing to research
- Identify research questions that need investigation
- Document initial ideas and constraints
- Separate "exploration" from "implementation"

---

## 🔄 Workflow

```
/explore [topic]
  → Creates exploration document
  → Identifies research topics/questions
  
/research [topic]
  → Conducts deep research
  → Creates research documents
  
/decision [topic]
  → Makes architectural decisions
  → Creates ADR documents
  
/transition-plan --from-adr
  → Transitions to feature planning
  → Creates feature plan + phases
```
